# theanhgen/homebrew-tap

Homebrew formulae for my tools.

```sh
brew install theanhgen/tap/flightydeck
```

| Formula | What |
|---|---|
| `flightydeck` | Unofficial CLI and MCP server for the Flighty macOS app. [Source](https://github.com/theanhgen/flightydeck) |

To update a formula after a release: set `url` to the new release tarball and `sha256` to the
value in the release's `.sha256` file.
